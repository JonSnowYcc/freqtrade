# Freqtrade 多交易所配置说明

## 概述

现在你有了三个配置文件，可以灵活地在不同交易所之间切换：

1. **config.json** - 默认配置（当前为OKX）
2. **config-binance.json** - 币安专用配置
3. **config-okx.json** - OKX专用配置

## 使用方法

### 1. 使用币安交易所

```bash
# 启动币安交易机器人
freqtrade trade --config user_data/config-binance.json

# 或者使用 --exchange 参数
freqtrade trade --config user_data/config.json --exchange binance
```

### 2. 使用OKX交易所

```bash
# 启动OKX交易机器人
freqtrade trade --config user_data/config-okx.json

# 或者使用默认配置（当前为OKX）
freqtrade trade --config user_data/config.json
```

### 3. 其他命令示例

```bash
# 下载币安数据
freqtrade download-data --config user_data/config-binance.json --pairs BTC/USDT ETH/USDT --timeframes 5m 15m 1h

# 下载OKX数据
freqtrade download-data --config user_data/config-okx.json --pairs BTC/USDT ETH/USDT --timeframes 5m 15m 1h

# 回测币安策略
freqtrade backtesting --config user_data/config-binance.json --strategy YourStrategy

# 回测OKX策略
freqtrade backtesting --config user_data/config-okx.json --strategy YourStrategy
```

## 配置文件特点

### 币安配置 (config-binance.json)
- **交易所**: binance
- **API密钥**: 已配置你的币安API密钥
- **代理**: 无代理设置
- **API服务器端口**: 8080

### OKX配置 (config-okx.json)
- **交易所**: okx
- **API密钥**: 已配置你的OKX API密钥
- **代理**: 配置了socks5代理 (127.0.0.1:7897)
- **API服务器端口**: 8081 (避免与币安配置冲突)

## 重要提醒

1. **安全性**: 请确保不要将包含真实API密钥的配置文件分享给任何人
2. **端口冲突**: 两个配置使用不同的API服务器端口（8080和8081）
3. **代理设置**: OKX配置包含代理设置，币安配置没有
4. **测试模式**: 所有配置都设置为 `dry_run: true`，建议先测试再切换到实盘

## 切换建议

- 如果主要使用币安，可以将 `config-binance.json` 重命名为 `config.json`
- 如果主要使用OKX，保持当前配置即可
- 可以同时运行两个机器人，但需要确保端口不冲突

## 故障排除

如果遇到连接问题：
1. 检查API密钥是否正确
2. 检查网络连接和代理设置
3. 确认交易所API权限设置
4. 查看日志文件获取详细错误信息
