## 价格发现配置详解

## price_side参数行为分析
price_side参数定义了价格发现的方向，支持'same'、'ask'、'bid'和'other'四种选项。该参数的行为根据交易方向（entry/exit）和持仓类型（long/short）而变化。

```mermaid
classDiagram
class PriceSideMapper {
+entry long same : bid
+entry long other : ask
+entry short same : ask
+entry short other : bid
+exit long same : ask
+exit long other : bid
+exit short same : bid
+exit short other : ask
}
class Exchange {
+_get_price_side(side, is_short, conf_strategy)
+get_rate(pair, refresh, side, is_short)
}
Exchange --> PriceSideMapper : "使用映射规则"
```

## 订单簿加权定价实现
当use_order_book设置为true时，系统通过订单簿数据实现加权定价。order_book_top参数指定使用订单簿的前N层深度数据，从而实现更精确的价格发现。

```mermaid
sequenceDiagram
participant 策略配置
participant 交易所模块
participant 交易所API
策略配置->>交易所模块 : get_rate(pair, entry, is_short)
交易所模块->>交易所模块 : _get_price_side()
交易所模块->>交易所模块 : use_order_book=true?
交易所模块->>交易所API : fetch_l2_order_book(pair, order_book_top)
交易所API-->>交易所模块 : 返回订单簿数据
交易所模块->>交易所模块 : _get_rate_from_ob()
交易所模块-->>策略配置 : 返回计算价格
```

## 混合定价策略中的price_last_balance
price_last_balance参数在混合定价策略中起到平衡作用，它允许在订单簿价格和最新成交价之间进行加权计算。该参数值为0到1之间的浮点数，表示最新价格的权重比例。

```mermaid
flowchart TD
Start([开始]) --> CheckSide{"交易方向?"}
CheckSide --> |entry| CheckPrice{"bid/ask > last?"}
CheckSide --> |exit| CheckPriceExit{"bid/ask < last?"}
CheckPrice --> |是| CalculateEntry["entry_rate = ask + balance * (last - ask)"]
CheckPrice --> |否| UseOrderBookPrice["使用订单簿价格"]
CheckPriceExit --> |是| CalculateExit["exit_rate = bid - balance * (bid - last)"]
CheckPriceExit --> |否| UseOrderBookPriceExit["使用订单簿价格"]
CalculateEntry --> End([结束])
UseOrderBookPrice --> End
CalculateExit --> End
UseOrderBookPriceExit --> End
```
