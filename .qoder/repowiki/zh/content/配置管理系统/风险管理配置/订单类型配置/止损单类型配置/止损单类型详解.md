## 止损单类型概述

止损单是交易策略中用于控制风险的重要工具。在Freqtrade中，止损单类型通过配置文件中的`order_types.stoploss`字段进行设置。该字段支持两种主要类型：市价单（market）和限价止损单（stop_loss_limit）。选择合适的止损单类型对于控制滑点风险和确保执行速度至关重要。

## 市价单与限价止损单的区别

市价单（market）和限价止损单（stop_loss_limit）在执行机制和风险特征上有显著区别。市价单旨在以当前市场价格立即执行，提供最快的执行速度，但可能面临较高的滑点风险，尤其是在市场波动剧烈时。限价止损单则在达到指定止损价格时，以预设的限价进行交易，可以更好地控制成交价格，但存在无法成交的风险。

在Freqtrade中，`OrderTypeValues`枚举定义了这两种类型：
```python
class OrderTypeValues(str, Enum):
    limit = "limit"
    market = "market"
```

市价单适用于需要快速退出市场以避免更大损失的场景，而限价止损单适用于希望在特定价格水平退出并愿意承担一定未成交风险的策略。

## 不同交易所对止损单类型的支持情况

不同的交易所对止损单类型的支持情况各不相同。例如，Binance期货市场支持限价和市价止损单，而Kraken则同时支持限价和市价止损单。Bybit和OKX也支持类似的止损单类型，但具体的参数和行为可能有所不同。

Binance的配置示例：
```python
_ft_has_futures: FtHas = {
    "stoploss_order_types": {"limit": "stop", "market": "stop_market"},
}
```

Kraken的配置示例：
```python
_ft_has: FtHas = {
    "stoploss_order_types": {"limit": "limit", "market": "market"},
}
```

这些配置表明，不同交易所对止损单类型的实现和支持程度存在差异，用户在选择交易所时应考虑这些因素。

## 配置文件中的止损单类型设置

在Freqtrade的配置文件中，止损单类型通过`order_types.stoploss`字段进行设置。以下是一个完整的配置示例：

```json
"order_types": {
    "entry": "limit",
    "exit": "limit",
    "emergency_exit": "market",
    "force_exit": "market",
    "force_entry": "market",
    "stoploss": "market",
    "stoploss_on_exchange": false,
    "stoploss_on_exchange_interval": 60,
    "stoploss_on_exchange_limit_ratio": 0.99
}
```

在这个配置中，`stoploss`字段设置为`market`，表示使用市价单作为止损单类型。如果需要使用限价止损单，可以将该字段设置为`limit`。此外，`stoploss_on_exchange`字段控制是否在交易所层面设置止损单，`stoploss_on_exchange_interval`字段定义了止损单的更新间隔。

## 与其他止损机制的兼容性

止损单类型与`trailing_stop`等其他止损机制具有良好的兼容性。`trailing_stop`允许止损价格随市场价格动态调整，从而锁定更多利润。当`trailing_stop`启用时，`order_types.stoploss`字段仍然决定止损单的执行类型。

例如，如果`trailing_stop`设置为`true`且`order_types.stoploss`设置为`market`，则止损单将以市价单的形式执行，同时止损价格会根据市场价格动态调整。这种组合可以在保护利润的同时，确保快速执行。

需要注意的是，如果`stoploss_on_exchange`设置为`true`，则止损单将在交易所层面设置，这可能会影响`trailing_stop`的行为。在这种情况下，止损单的调整需要通过交易所的API进行，可能会引入额外的延迟。
