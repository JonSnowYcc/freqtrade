## 现货与期货交易模式概述
在 Freqtrade 框架中，交易模式通过 `TradingMode` 枚举类定义，包括现货（SPOT）、保证金（MARGIN）和期货（FUTURES）三种模式。不同的交易模式对策略的实现有不同的要求，特别是在入口和出口信号的生成方法上。

## 方法实现要求
### 期货模式
在期货模式下，策略必须实现 `populate_entry_trend` 和 `populate_exit_trend` 方法。这些方法是强制性的，用于生成入口和出口信号。如果未实现这些方法，系统将抛出 `OperationalException`。

### 现货模式
在现货模式下，策略可以使用 `populate_buy_trend` 和 `populate_sell_trend` 方法作为替代。然而，推荐使用 `populate_entry_trend` 和 `populate_exit_trend` 方法，因为它们提供了更一致的接口。

## 入口/出口趋势与买卖趋势的区分
### 为何要强制区分
强制区分入口/出口趋势而非买卖趋势的原因在于，入口和出口信号的逻辑可能更为复杂，不仅仅局限于简单的买入和卖出操作。例如，在期货模式下，可能存在做空和做多两种方向，而不仅仅是买入和卖出。通过使用 `populate_entry_trend` 和 `populate_exit_trend` 方法，可以更好地支持这些复杂的交易逻辑。

### 优势
- **灵活性**：支持多种交易方向，如做多和做空。
- **一致性**：提供统一的接口，便于策略的维护和扩展。
- **可读性**：代码更加清晰，易于理解和维护。

## 代码示例
### 期货模式下的实现
```python
class FuturesStrategy(IStrategy):
    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 实现入口信号逻辑
        dataframe.loc[
            (
                (dataframe['rsi'] < 30) &
                (dataframe['macd'] > 0)
            ),
            'enter_long'
        ] = 1
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 实现出口信号逻辑
        dataframe.loc[
            (
                (dataframe['rsi'] > 70) &
                (dataframe['macd'] < 0)
            ),
            'exit_long'
        ] = 1
        return dataframe
```

### 现货模式下的实现
```python
class SpotStrategy(IStrategy):
    def populate_buy_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 实现买入信号逻辑
        dataframe.loc[
            (
                (dataframe['rsi'] < 30) &
                (dataframe['macd'] > 0)
            ),
            'buy'
        ] = 1
        return dataframe

    def populate_sell_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 实现卖出信号逻辑
        dataframe.loc[
            (
                (dataframe['rsi'] > 70) &
                (dataframe['macd'] < 0)
            ),
            'sell'
        ] = 1
        return dataframe
```

## 未实现必需方法的处理机制
当策略未实现必需的方法时，系统会在 `validate_strategy` 方法中进行检查，并抛出 `OperationalException`。具体来说，如果在期货模式下未实现 `populate_entry_trend` 或 `populate_exit_trend` 方法，或者在现货模式下未实现 `populate_buy_trend` 或 `populate_sell_trend` 方法，都会触发异常。

```python
if not check_override(strategy, IStrategy, "populate_entry_trend"):
    raise OperationalException("`populate_entry_trend` must be implemented.")
if not check_override(strategy, IStrategy, "populate_exit_trend"):
    raise OperationalException("`populate_exit_trend` must be implemented.")
```
