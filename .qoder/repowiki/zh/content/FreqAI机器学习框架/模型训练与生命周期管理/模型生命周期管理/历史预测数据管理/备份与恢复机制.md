本文档全面阐述了FreqAI系统中历史预测数据的备份与恢复机制。系统通过自动创建备份文件和智能异常处理流程，确保在主文件损坏时能够无缝切换到备份文件，从而提高系统的可靠性和数据安全性。

## 备份机制
系统在每次保存`historic_predictions.pkl`文件后，会自动创建`historic_predictions.backup.pkl`备份文件。这一过程通过`save_historic_predictions_to_disk`方法实现，确保了数据的双重保护。

```mermaid
flowchart TD
Start([开始保存历史预测]) --> SaveMain["保存主文件 historic_predictions.pkl"]
SaveMain --> CreateBackup["创建备份文件 historic_predictions.backup.pkl"]
CreateBackup --> CopyFile["使用shutil.copy复制文件"]
CopyFile --> End([保存完成])
```

## 恢复机制
当主文件因EOFError损坏时，系统会自动切换到备份文件进行恢复。`load_historic_predictions_from_disk`方法首先尝试加载主文件，如果遇到EOFError，则会自动加载备份文件。

```mermaid
sequenceDiagram
participant System as 系统
participant MainFile as 主文件
participant BackupFile as 备份文件
System->>MainFile : 尝试加载 historic_predictions.pkl
alt 文件正常
MainFile-->>System : 成功加载数据
System->>System : 记录信息日志
else 文件损坏
MainFile--x System : EOFError异常
System->>BackupFile : 尝试加载 historic_predictions.backup.pkl
BackupFile-->>System : 成功加载备份数据
System->>System : 记录警告日志
end
```

## 数据不准确警告
系统在长时间离线后可能出现数据不准确的情况。当成功加载历史预测文件时，系统会发出警告，提醒用户统计数据可能不准确。

```mermaid
flowchart LR
A[发现现有历史预测] --> B[检查离线时间]
B --> C{离线时间过长?}
C --> |是| D[发出数据不准确警告]
C --> |否| E[正常加载数据]
D --> F[继续运行]
E --> F
```
