## 引言
FreqAI系统通过精细化的模型缓存与生命周期管理策略，确保机器学习模型在交易决策中的可靠性与时效性。本文档深入解析其核心机制，包括模型过期判断、内存元数据维护、磁盘缓存清理等关键组件，揭示系统如何在保证性能的同时维持模型的预测准确性。

## 模型生命周期管理
FreqAI的模型生命周期由`FreqaiDataDrawer`和`FreqaiDataKitchen`两个核心类协同管理。`FreqaiDataDrawer`负责模型的持久化存储、内存缓存和元数据管理，而`FreqaiDataKitchen`则专注于模型的训练、预测和过期判断。这种职责分离的设计确保了模型管理的高效性与可靠性。

## 模型过期判断机制
模型的过期判断由`FreqaiDataKitchen`类中的`check_if_model_expired`方法实现。该机制基于配置项`expiration_hours`，通过比较当前时间戳与模型的训练时间戳来判断模型是否过期。

```mermaid
flowchart TD
Start([开始]) --> GetCurrentTime["获取当前时间戳"]
GetCurrentTime --> CalculateElapsed["计算已过时间(小时)"]
CalculateElapsed --> CheckConfig["检查配置项 expiration_hours"]
CheckConfig --> |大于0| CompareTime["比较已过时间 > expiration_hours"]
CompareTime --> |是| ReturnExpired["返回: 模型已过期"]
CompareTime --> |否| ReturnValid["返回: 模型有效"]
CheckConfig --> |等于0| ReturnValid
ReturnExpired --> End([结束])
ReturnValid --> End
```

## 内存元数据管理
### pair_dict 字典
`pair_dict`是`FreqaiDataDrawer`类中的核心字典，用于在内存中维护所有交易对的模型元数据。其结构定义为`dict[str, pair_info]`，其中`pair_info`是一个包含模型文件名、训练时间戳、数据路径等信息的类型字典。

```mermaid
classDiagram
class pair_info {
+model_filename : str
+trained_timestamp : int
+data_path : str
+extras : dict
}
class FreqaiDataDrawer {
+pair_dict : dict[str, pair_info]
+model_dictionary : dict[str, Any]
+meta_data_dictionary : dict[str, dict[str, Any]]
+historic_predictions : dict[str, DataFrame]
}
FreqaiDataDrawer --> pair_info : "包含"
```

### save_lock 与元数据持久化
为确保元数据文件写入的原子性，`FreqaiDataDrawer`使用`save_lock`（`threading.Lock`实例）来同步对持久化文件的访问。当需要保存`pair_dict`或其他元数据时，系统会先获取锁，完成写入操作后再释放锁，防止并发写入导致的数据损坏。

```mermaid
sequenceDiagram
participant ThreadA as "线程A"
participant ThreadB as "线程B"
participant SaveLock as "save_lock"
ThreadA->>SaveLock : acquire()
SaveLock-->>ThreadA : 获取锁
ThreadA->>SaveLock : 写入pair_dictionary.json
ThreadA->>SaveLock : release()
ThreadB->>SaveLock : acquire()
Note over ThreadB,SaveLock : 等待线程A释放锁
SaveLock-->>ThreadB : 获取锁
ThreadB->>SaveLock : 写入pair_dictionary.json
ThreadB->>SaveLock : release()
```

### empty_pair_dict 初始化
`empty_pair_dict`是一个预定义的`pair_info`字典，用于初始化新交易对的元数据。当系统首次处理某个交易对时，会使用`empty_pair_dict`的副本进行初始化，确保所有字段都有默认值。

```python
self.empty_pair_dict: pair_info = {
    "model_filename": "",
    "trained_timestamp": 0,
    "data_path": "",
    "extras": {},
}
```

## 模型缓存清理策略
### purge_old_models 方法
`purge_old_models`方法实现了基于配置的模型缓存清理策略。该方法根据`purge_old_models`配置项，自动清理过期的模型文件夹。

```mermaid
flowchart TD
Start([开始 purge_old_models]) --> GetConfig["获取 purge_old_models 配置"]
GetConfig --> CheckConfig["检查配置有效性"]
CheckConfig --> |无效| End([结束])
CheckConfig --> |有效| ListFolders["列出模型目录下的所有文件夹"]
ListFolders --> DefinePattern["定义正则表达式: sub-train-(\\w+)_(\\d{10})"]
DefinePattern --> ProcessFolders["遍历每个文件夹"]
ProcessFolders --> MatchPattern["匹配正则表达式"]
MatchPattern --> |匹配失败| SkipFolder["跳过"]
MatchPattern --> |匹配成功| ExtractInfo["提取交易对和时间戳"]
ExtractInfo --> GroupByPair["按交易对分组"]
GroupByPair --> SortByTime["按时间戳排序"]
SortByTime --> CalculateDelete["计算需删除数量 = 总数 - 保留数"]
CalculateDelete --> DeleteOld["删除最旧的 N 个模型"]
DeleteOld --> LogDeletion["记录删除日志"]
LogDeletion --> End
```
