## 信号生成流程

### do_predict标志位机制
`do_predict`标志位作为有效预测指示器，其值为1时表示模型对当前预测结果具有足够信心。该标志位由FreqAI系统在数据预处理阶段生成，用于过滤掉因数据缺失或模型不确定性导致的不可靠预测。

```mermaid
flowchart TD
Start([开始]) --> CheckNaN["检查数据是否包含NaN"]
CheckNaN --> HasNaN{"存在NaN?"}
HasNaN --> |是| SetDoPredict0["设置do_predict=0"]
HasNaN --> |否| CheckModelConfidence["检查模型置信度"]
CheckModelConfidence --> LowConfidence{"置信度低?"}
LowConfidence --> |是| SetDoPredict0
LowConfidence --> |否| SetDoPredict1["设置do_predict=1"]
SetDoPredict0 --> End([结束])
SetDoPredict1 --> End
```

### 预测收益率判断
`&-s_close`预测值表示模型对未来价格变动的预测收益率。正数表示预测价格上涨（多头机会），负数表示预测价格下跌（空头机会）。通过设置阈值来判断交易机会：

- 多头进入：`&-s_close > 0.01`（预测收益率超过1%）
- 空头进入：`&-s_close < -0.01`（预测收益率低于-1%）
- 多头退出：`&-s_close < 0`（预测收益率转为负值）
- 空头退出：`&-s_close > 0`（预测收益率转为正值）

## 进入退出条件构建

### 多条件组合编程模式
使用`reduce`函数将多个进入条件进行逻辑与（&）组合，确保所有条件同时满足时才触发交易信号。这种模式提高了信号的可靠性。

```mermaid
classDiagram
class EnterLongConditions {
+List[Condition] conditions
+do_predict == 1
+&-s_close > 0.01
}
class EnterShortConditions {
+List[Condition] conditions
+do_predict == 1
+&-s_close < -0.01
}
class ExitLongConditions {
+List[Condition] conditions
+do_predict == 1
+&-s_close < 0
}
class ExitShortConditions {
+List[Condition] conditions
+do_predict == 1
+&-s_close > 0
}
EnterLongConditions --> reduce : "组合"
EnterShortConditions --> reduce : "组合"
ExitLongConditions --> reduce : "组合"
ExitShortConditions --> reduce : "组合"
```

## 风险管理协同

### ROI与止损参数
信号生成逻辑与风险管理参数协同工作，形成完整的交易决策系统：

- `minimal_roi`：定义了不同持有时间的最小收益率目标
- `stoploss`：设置最大可接受亏损比例
- `use_exit_signal`：启用基于指标的退出信号

```mermaid
erDiagram
SIGNAL_GENERATION ||--o{ RISK_MANAGEMENT : "协同工作"
SIGNAL_GENERATION {
string do_predict
float s_close
}
RISK_MANAGEMENT {
json minimal_roi
float stoploss
boolean use_exit_signal
}
```

## 交易确认机制

### confirm_trade_entry方法
`confirm_trade_entry`方法实现基于最新市场数据的交易确认，防止滑点过大导致的不利成交。该方法在交易执行前被调用，通过比较当前报价与最新收盘价来控制成交质量。

```mermaid
sequenceDiagram
participant Strategy as "策略"
participant Confirm as "confirm_trade_entry"
participant DP as "DataProvider"
Strategy->>Confirm : 请求交易确认
Confirm->>DP : 获取最新分析数据
DP-->>Confirm : 返回分析数据
Confirm->>Confirm : 检查滑点
alt 长仓检查
Confirm->>Confirm : rate > close * 1.0025?
Confirm-->>Strategy : 返回False(拒绝)
else 短仓检查
Confirm->>Confirm : rate < close * 0.9975?
Confirm-->>Strategy : 返回False(拒绝)
else 通过检查
Confirm-->>Strategy : 返回True(确认)
end
```
