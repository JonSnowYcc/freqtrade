## 引言
FreqAI框架提供了一套强大的特征工程机制，允许用户通过配置文件灵活地扩展和处理交易数据。本文档深入解析`indicator_periods_candles`和`include_shifted_candles`两个核心参数的工作原理，重点分析`data_kitchen.py`中的`populate_features`方法以及`FreqaiExampleStrategy.py`中的`feature_engineering_expand_all`与`feature_engineering_expand_basic`方法。

## 特征扩展机制

FreqAI框架通过`indicator_periods_candles`参数实现同一指标在不同周期下的特征扩展。该参数定义在配置文件的`feature_parameters`部分，是一个包含多个整数的数组，每个整数代表一个计算周期。

在`data_kitchen.py`的`populate_features`方法中，系统遍历`indicator_periods_candles`数组中的每个周期值`t`，并调用策略中的`feature_engineering_expand_all`方法。此过程通过循环实现，为每个指定周期生成相应的技术指标。

策略类中的`feature_engineering_expand_all`方法负责实际的指标计算。该方法接收一个周期参数，并使用TA-Lib等库计算RSI、MFI、ADX等多种技术指标。所有生成的特征列名必须以`%`开头，以便FreqAI系统识别。

## 移位K线处理

FreqAI框架通过`include_shifted_candles`参数实现历史K线特征的移位处理。该参数控制着系统将特征数据进行时间偏移（shift）操作的程度。

在`populate_features`方法中，系统首先识别所有以`%`开头的特征列，然后对这些列执行`shift(n)`操作，其中`n`是从1到`include_shifted_candles`值的整数。每次偏移后，系统会为新生成的列添加`_shift-n`后缀，并将其与原始数据合并。

这种移位处理允许模型访问历史特征数据，从而更好地捕捉时间序列中的模式和趋势。例如，当`include_shifted_candles=2`时，系统会生成包含前1根和前2根K线特征的数据集。

```mermaid

A[原始特征数据] --> B{n ≤ include_shifted_candles?}
B --> |是| C[执行shift(n)操作]
C --> D[添加_shift-n后缀]
D --> E[与原始数据合并]
E --> B
B --> |否| F[完成移位处理]
```

## 数据流完整示例

以下展示了特征扩展与移位的完整数据流：

1. 系统读取配置文件中的`indicator_periods_candles`和`include_shifted_candles`参数
2. 遍历所有指定的时间框架（`include_timeframes`）
3. 对每个时间框架，获取相应的K线数据
4. 对`indicator_periods_candles`中的每个周期，调用`feature_engineering_expand_all`
5. 调用`feature_engineering_expand_basic`处理基础特征
6. 对生成的所有特征执行移位操作，次数等于`include_shifted_candles`的值
7. 将所有处理后的特征合并到最终的数据集中

此流程确保了特征数据的全面性和多样性，为机器学习模型提供了丰富的输入信息。

## 配置参数详解

| 参数名称 | 类型 | 默认值 | 说明 |
|--------|-----|-------|------|
| indicator_periods_candles | 数组 | - | 指标计算周期数组，如[10, 20, 30] |
| include_shifted_candles | 整数 | 0 | 移位K线数量，0表示不移位 |
| include_timeframes | 数组 | - | 包含的时间框架，如["5m", "15m"] |
| include_corr_pairlist | 数组 | [] | 相关交易对列表 |

这些参数共同作用，决定了特征工程的广度和深度。`indicator_periods_candles`直接影响特征的数量，而`include_shifted_candles`则影响模型对历史数据的记忆能力。
